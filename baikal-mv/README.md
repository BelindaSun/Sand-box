# 《冰下的夏天》—— 《贝加尔湖畔》MV

同一片湖，两个季节。他在冬天回来，她在夏天回来，两个人都回来过，只是没有在同一个季节。

整片画面由代码逐帧绘制（Canvas 2D），用 Playwright 渲染成 1920×1080、24fps 的视频，时长 4:07，按 Belinda 网站上的《贝加尔湖畔》录音（4:05.8）逐段对齐：视频时间就等于歌曲时间。

## 成片

| 文件 | 说明 |
|---|---|
| `out/冰下的夏天_MV_720p.mp4` | 成片 720p，只有环境音：冰裂声、风、火柴、篝火、火车、湖水 |
| `out/ambience.m4a` | 单独的环境音轨 |
| `site/` | 网站 hello-human-39 的新正文（中、英）和给小缪的交接说明 |

带歌的版本（`site/deliver/hello-human-39-2.mp4`）没有提交到这个仓库，因为歌曲版权属于原作者。重新生成的方法见文末。

## 三种画面质感

| 时间线 | 画幅 | 质感 |
|---|---|---|
| 记忆（年轻的夏天） | 4:3 左右黑边 | 16mm 胶片：暖色、颗粒、画面轻微晃动、闪烁、灰尘 |
| 他（现在，冬天） | 2.39:1 上下黑边 | 冷色，固定机位，大面积白色 |
| 她（现在，夏天） | 2.39:1 上下黑边 | 冷暖适中，固定机位 |

观众靠画幅就能分辨"记忆"和"现在"。第 14 镜第一次出现宽画幅的夏天，就是她出场的时刻。

## 重新渲染

```bash
pip install imageio-ffmpeg scipy numpy
export FFMPEG=$(python3 -c "import imageio_ffmpeg;print(imageio_ffmpeg.get_ffmpeg_exe())")
node render.mjs video out/video_silent.mp4 0 247 4     # 画面（4 个进程并行）
node dump.mjs && python3 sound.py                      # 环境音轨
$FFMPEG -i out/video_silent.mp4 -i out/ambience.wav -c:v copy -c:a aac -b:a 192k out/master.mp4
# 带歌的版本：先把 baikal.mp3 转成 48kHz 的 out/song48.wav，与 ambience 按 -14 dB 混成 out/mix.wav，再替换音轨
node render.mjs sheet frames/all.jpg all 0.6           # 每个镜头一帧的联系表
```

- `src/lib.js`：画幅、胶片质感、人物骨骼、火、布条、冰、水等绘制零件
- `src/shots.js`：31 个镜头，每个镜头的时长写在 `S('编号 名称', 时长, ...)` 里
- `sound.py`：环境音合成，事件时间按镜头自动对齐
