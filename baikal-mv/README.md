# 《冰下的夏天》—— 《贝加尔湖畔》MV

同一片湖，两个季节。他在冬天回来，她在夏天回来，两个人都回来过，只是没有在同一个季节。

整片画面由代码逐帧绘制（Canvas 2D），用 Playwright 渲染成 1920×1080、24fps 的视频，时长 4:16。

## 成片

| 文件 | 说明 |
|---|---|
| `out/冰下的夏天_MV_720p.mp4` | 成片 720p（22MB，方便在手机上看） |
| `out/冰下的夏天_MV_1080p.mp4` | 成片 1080p（116MB） |
| `out/ambience.m4a` | 单独的环境音轨：冰裂声、风、火柴、篝火、火车、湖水 |

**歌曲没有放进去。** 这里没有原曲音频，而且版权属于原作者。你可以在剪辑软件里把原曲铺在成片上，环境音已经压低，可以当作底层垫音。

## 三种画面质感

| 时间线 | 画幅 | 质感 |
|---|---|---|
| 记忆（年轻的夏天） | 4:3 左右黑边 | 16mm 胶片：暖色、颗粒、画面轻微晃动、闪烁、灰尘 |
| 他（现在，冬天） | 2.39:1 上下黑边 | 冷色，固定机位，大面积白色 |
| 她（现在，夏天） | 2.39:1 上下黑边 | 冷暖适中，固定机位 |

观众靠画幅就能分辨"记忆"和"现在"。第 14 镜第一次出现宽画幅的夏天，就是她出场的时刻。

## 和原曲对齐

表里的段落时间是**按歌曲结构估计的**，不是按原曲精确卡点。不同版本（录音室版、现场版）的时长也不一样。

最省事的做法：把你用的版本里每段的起始时间告诉我，比如"主歌一 0:24，副歌一 1:52"，我按比例调整各镜头时长，重新渲染一遍，十几分钟就能完成。

## 重新渲染

```bash
pip install imageio-ffmpeg scipy numpy
export FFMPEG=$(python3 -c "import imageio_ffmpeg;print(imageio_ffmpeg.get_ffmpeg_exe())")
node render.mjs video out/video_silent.mp4 0 256 4     # 画面（4 个进程并行）
node dump.mjs && python3 sound.py                      # 环境音轨
$FFMPEG -i out/video_silent.mp4 -i out/ambience.wav -c:v copy -c:a aac -b:a 192k -shortest out/master.mp4
node render.mjs sheet frames/all.jpg all 0.6           # 每个镜头一帧的联系表
```

- `src/lib.js`：画幅、胶片质感、人物骨骼、火、布条、冰、水等绘制零件
- `src/shots.js`：31 个镜头，每个镜头的时长写在 `S('编号 名称', 时长, ...)` 里
- `sound.py`：环境音合成，事件时间按镜头自动对齐
