## 背景音乐按钮（建议加）

片子里已经有歌了。如果读者开着左栏的「♪ 背景音乐」再去点视频，会听到两份歌叠在一起。在页面底部现有的 `<script>` 后面加这几行，视频一开始播放，就自动暂停背景音乐：

```html
<script>
(function(){
  var v = document.getElementById('film'), a = document.getElementById('bgm'), b = document.getElementById('musicBtn');
  if (!v || !a) return;
  v.addEventListener('play', function(){ if (!a.paused) { a.pause(); b && b.classList.remove('playing'); } });
})();
</script>
```

中文页和英文页都要加。
